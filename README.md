# 🚩 आपला दादा - नागरी तक्रार निवारण कक्ष (विटा-खानापूर)
### लोकनेते मा. श्री. वैभव (दादा) पाटील जनसंपर्क कार्यालय, विटा-खानापूर

'आपला दादा' हे विटा-खानापूर विधानसभा मतदारसंघातील नागरिकांसाठी तयार केलेले आधुनिक, सुरक्षित आणि संपूर्ण **मराठी भाषेतील** नागरी तक्रार निवारण व्यासपीठ आहे. हे ॲप-स्तरीय (App-level) इंटरफेसवर आधारित असून मोबाईलवर झूम होत नाही (`user-scalable=no, maximum-scale=1.0`) आणि मोबाईल व लॅपटॉप दोन्हीवर उत्कृष्ट चालते.

## 🌟 महत्त्वाच्या सुधारणा व वैशिष्ट्ये (Production Enhancements)

### १. व्यावसायिक व सुटसुटीत युझर इंटरफेस (Professional Civic UI):
- कॅटेगरीज आणि टॅब्समधील सर्व अनौपचारिक इमोजी काढून त्याजागी **अधिकृत व्हेक्टर आयकॉन्स (Lucide SVG Icons)** वापरले आहेत:
  - **रस्ते दुरुस्ती व खड्डे:** `Route` आयकॉन
  - **पाणी पुरवठा व गळती:** `Droplets` आयकॉन
  - **नगरपालिका / ग्रामपंचायत नागरी सुविधा:** `Building2` आयकॉन
  - **वीज पुरवठा व पथदिवे:** `Zap` आयकॉन
  - **शासकीय योजना लाभ:** `FileCheck2` आयकॉन
  - **कचरा व स्वच्छता:** `Trash2` आयकॉन
  - **इतर सार्वजनिक समस्या:** `HelpCircle` आयकॉन
- सर्व चाचणी / डेमो घटक आणि बटणे काढून पूर्णपणे प्रॉडक्शन-रेडी सॉफ्टवेअर तयार केले आहे.

### २. Firebase Cloud Firestore एकत्रीकरण (Render वरील अखंड डेटा सुरक्षितता):
- **Render वर समस्या काय येते?** Render च्या मोफत प्लॅनवर सर्व्हर १५ मिनिटांनंतर स्लीप मोडमध्ये जातो आणि नवीन डिप्लॉयमेंट किंवा रीस्टार्ट झाल्यावर स्थानिक फाईल सिस्टीम रिसेट होते.
- **Firebase ने हा प्रश्न कसा सोडवला?**
  - पोर्टलमध्ये थेट **Firebase Cloud Firestore** जोडण्यात आले आहे.
  - सर्व नागरिकांचे लॉगिन आयडी, पासवर्ड, तक्रारी, छायाचित्रे, स्थिती आणि ईमेल लॉग **Firebase च्या क्लाउड डेटाबेसमध्ये कायमस्वरूपी सुरक्षित साठवले जातात**.
  - Render सर्व्हर कितीही वेळा रीस्टार्ट किंवा स्लीप झाला, तरी डेटा १% ही नष्ट होत नाही!

## ☁️ Firebase कसे कॉन्फिगर करावे (Firebase Setup Guide)

1. [Firebase Console](https://console.firebase.google.com/) वर जाऊन नवीन प्रकल्प (Project) तयार करा.
2. डाव्या बाजूला **Firestore Database** निवडून **Create database** वर क्लिक करा.
3. वर डाव्या कोपऱ्यातील **Project Settings (गिअर आयकॉन)** ➔ **Service accounts** टॅबवर जा.
4. **Generate new private key** या बटणावर क्लिक करा. एक JSON फाईल डाऊनलोड होईल.
5. **Render वर डिप्लॉय करताना:**
   - Render Dashboard ➔ Environment Variables मध्ये जा.
   - Key: `FIREBASE_CREDENTIALS_JSON`
   - Value: डाऊनलोड केलेल्या JSON फाईलमधील संपूर्ण मजकूर कॉपी करून येथे पेस्ट करा.
6. **स्थानिक पातळीवर चालवताना:**
   - ती फाईल `firebase_credentials.json` नावाने प्रोजेक्टच्या मुख्य फोल्डरमध्ये ठेवा.
   *(टीप: जोपर्यंत Firebase जोडले जात नाही, तोपर्यंत ॲप स्थानिक डेटाबेसवर स्वयंचलित काम करते.)*

## 🚀 Render वर डिप्लॉय कसे करावे (Render Deployment)

या रिपॉझिटरीमध्ये `render.yaml`, `Procfile` आणि `requirements.txt` आधीच समाविष्ट केले आहेत.

### पायरी १: GitHub वर कोड पुश करा
```bash
git add .
git commit -m "Aapla Dada production ready portal with Firebase and clean civic UI"
git push origin main
```

### पायरी २: Render वर जोडा
1. [Render.com](https://render.com) वर लॉगिन करा.
2. **New +** ➔ **Web Service** निवडा आणि आपली GitHub रिपॉझिटरी निवडा.
3. खालील सेटिंग्ज तपासा:
   - **Environment:** `Python`
   - **Build Command:** `pip install -r requirements.txt && cd frontend && npm install && npm run build && cd ..`
   - **Start Command:** `python run.py`
4. **Environment Variables** जोडा:
   - `ADMIN_USERNAME`: `admin`
   - `ADMIN_PASSWORD`: `dada@123`
   - `FIREBASE_CREDENTIALS_JSON`: *(आपल्या Firebase JSON चा मजकूर)*
   - `SMTP_USER`: *(आपला ईमेल आयडी)*
   - `SMTP_PASSWORD`: *(Gmail App Password)*
   - `OFFICE_NOTIFICATION_EMAIL`: `office.vaibhavdada@gmail.com`

## 📋 नागरिक व प्रशासकीय कार्यप्रणाली

### १. नागरिक विभाग (३ मुख्य टॅब्स):
* **टॅब १: नवीन तक्रार नोंदणी:** रस्ते, पाणी, वीज, नगरपालिका, शासकीय योजना आणि इतर समस्यांसाठी सुटसुटीत अर्ज. फोटो जोडण्याची सुविधा.
* **टॅब २: दादांची विकासकामे:** सामायिक केलेल्या ४ फोटोंवर आधारित अस्सल मराठीतील सविस्तर निरीक्षणे (नागरी पाहणी, NSS युवा शिबीर, पर्यावरण श्रमदान, मा. राष्ट्रपती महोदयांच्या हस्ते राष्ट्रीय गौरव).
* **टॅब ३: माझ्या तक्रारी:** दाखल केलेल्या तक्रारींची सद्यस्थिती. दादांच्या कार्यालयाने तक्रार सोडवल्यानंतर येथे हिरवा **'निकाली काढली (Done)'** बॅज आणि कार्यालयाचा अधिकृत अहवाल दिसतो.

### २. प्रशासकीय कक्ष (Admin Dashboard):
* **लॉगिन:** `admin` / `dada@123` (किंवा `.env` मधील पासवर्ड)
* **१-क्लिक 'निकाली काढा' (Mark as Done):** अधिकृत शेरा प्रविष्ट करून तक्रार निकाली काढताच नागरिकांच्या स्क्रीनवर तात्काळ अपडेट होते.
* **SMTP ईमेल आउटबॉक्स:** कार्यालयास पाठवले जाणारे सर्व अधिकृत ईमेल पाहण्याची सोय.
